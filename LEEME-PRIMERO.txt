SECCIÓN 🥗 NUTRICIÓN — CRM EntrenaConMétodo
===========================================

OJO: GitHub NO descomprime archivos .zip. Si arrastras el .zip al repo,
se sube el .zip tal cual y no sirve de nada. Por eso primero descomprimes
en tu computador (ya lo hiciste si estás leyendo esto) y luego subes ESTOS
archivos.


PASO 1 · SUBIR LOS ARCHIVOS (una sola vez)
------------------------------------------
1. Entra a github.com/morongmauro/CRM_entrenaconmetodo
2. Botón "Add file" → "Upload files"
3. Abre esta carpeta, selecciona TODO su contenido (Ctrl+A / Cmd+A):
   los 5 archivos sueltos MÁS la carpeta "api"
   -> NO arrastres esta carpeta entera, arrastra lo que hay DENTRO.
      Si arrastras la carpeta, te crea "crm-nutricion/" en el repo.
4. Suéltalo en la zona de GitHub. Verás que reconoce "api/coach-insight.js"
   con la ruta completa: eso es lo correcto.
5. Puedes borrar este LEEME de la lista antes de confirmar (no estorba,
   pero no hace falta subirlo).
6. Commit.

Los 5 archivos de la raíz REEMPLAZAN los que ya están.
api/coach-insight.js es NUEVO.


PASO 2 · VARIABLE DE ENTORNO EN VERCEL
--------------------------------------
Solo hace falta para el botón de "Oportunidades de mejora". El resto de
la sección funciona sin esto.

Vercel → proyecto del CRM → Settings → Environment Variables
  Name:  ANTHROPIC_API_KEY
  Value: tu key de Anthropic (la misma del Mealtracker sirve)
  Marca los tres entornos → Save

Después: Deployments → ⋯ → Redeploy
(las variables nuevas SOLO entran con un despliegue nuevo)


PASO 3 · TABLA EN SUPABASE (opcional)
-------------------------------------
Supabase (proyecto del CRM) → SQL Editor → New query
Pega el contenido de schema.sql → Run

Es seguro correrlo completo: todo es "create table if not exists" y no hay
un solo drop/delete/truncate. No toca tus datos.
Si prefieres lo mínimo, copia solo el bloque final, desde
"create table if not exists nutricion_insights".

Sin este paso la sección funciona igual, solo que no recuerda los análisis
ya generados: cada vez que abras una semana tendrías que regenerarlos.

CÓMO SE USA
-----------
Barra de navegación → 🥗 Nutrición
  · Elige cliente y navega semana a semana con ← →
  · Resumen    : la semana graficada contra su meta, macros, micros, patrones
  · Alimentos  : lo que más calorías aportó, lo que más repite, mejor y peor
                 densidad nutricional, y la tabla completa
  · Día a día  : cada comida con sus alimentos, tal cual la registró
  · Oportunidades : las 3-5 palancas del coach, con el mensaje listo para
                    copiarle al cliente por WhatsApp

Costo aproximado del botón de oportunidades: ~USD 0,12 por análisis
(~500 COP). Se guarda: reabrir una semana ya analizada no cuesta nada.
